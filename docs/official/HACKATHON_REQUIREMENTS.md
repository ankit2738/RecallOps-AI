# Hackathon Official Requirements Summary

## Challenge
AI Agents That Learn Using Hindsight.

## Mandatory Technology
- All teams must build using Hindsight.
- Participants must download and use Band AI Desktop.
- Any LLM can be used.
- Groq is recommended as a fast option with a free tier.

## Selected Problem
Engineering & DevOps — Incident Response Agent.

The agent should remember previous incidents, root causes, resolution steps and successful runbooks. It should use past incident knowledge to recommend solutions for new incidents.

## Official Judging Criteria

| Criterion | Weight |
|---|---:|
| Innovation | 30% |
| Hindsight Memory | 25% |
| Technical Implementation | 20% |
| User Experience | 15% |
| Real-world Impact | 10% |

## What Judges Expect
- Solve a real professional or business problem.
- Make Hindsight memory central to the product.
- Demonstrate improvement over multiple interactions.
- Show actual historical memory retrieval.
- Demonstrate a clear before-and-after comparison.
- Deliver a compelling demonstration within approximately 60 seconds.
- Keep the product focused and polished.
- Use realistic data, clearly labelling synthetic data.

## Submission Requirements
- Clean, documented GitHub repository.
- Live project demonstration.
- Demo video.
- Explanation of Hindsight integration.
- Individual article from every team member.
- Individual social media post from every team member.
- One team video.

## Content Contest Rules
Articles:
- Public and linkable.
- English.
- Overview specifies 800–1,500 words.
- Detailed instructions specify 1,200–2,000 words.
- Recommended target: 1,200–1,500 words.
- No mention of the hackathon in the article title or body.
- Include actual code, screenshots, Hindsight integration and honest lessons.

LinkedIn:
- Under 800 characters.
- Do not mention the hackathon.
- Include the project GitHub repository link.
- Include the article URL in the first comment.
- Include the Hindsight GitHub link in a separate comment.
- Use 3–5 relevant hashtags at the end.

Team Video:
- 2–5 minutes.
- Minimum 1080p.
- Public YouTube upload.
- Show a real interaction.
- Demonstrate Hindsight retain and recall operations.
